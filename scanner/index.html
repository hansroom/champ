      스크립트 · 자막 분석

      영상을 선택하면 설명문·해시태그·챕터를 자동 수집합니다. 자막 원문은 브라우저 보안(CORS) 때문에 직접 호출이 막혀 있어, 설정에서 프록시를 지정하거나 아래에 직접 붙여넣으면 동일하게 분석됩니다.

      설정

      Google Cloud Console → API 및 서비스 → 사용자 인증 정보에서 발급합니다. 키는 이 브라우저의 localStorage에만 저장되며 외부로 전송되지 않습니다.

      입력한 주소 뒤에 자막 URL이 인코딩되어 붙습니다. 비워두면 자막 자동 수집을 건너뜁니다.
