# 보통의민주 정치 쇼츠 파이프라인

원본 영상의 **지정 구간만** 내려받아 분석하고, 45~60초 본편 + 2~4초 콜드 오픈 HOOK 구조의
9:16 쇼츠(1080×1920 / H.264)를 만든다.

## 설치

```bash
pip install -r requirements.txt
```

한글 폰트가 반드시 필요하다 (헤드라인 렌더링). 없으면 글자가 □□□ 로 나온다.

```bash
# Debian/Ubuntu
sudo apt-get install -y fonts-nanum
# macOS 는 AppleSDGothicNeo 가 기본 설치돼 있음
```

## 사용

```bash
JOB=job-Fl9sPXasRWU.json

# 1) 00:24:20~00:35:54 구간만 다운로드 + 자막 확보  (전체 영상은 받지 않는다)
python3 make_short.py fetch --job $JOB

# 2) 주제 키워드로 45~60초 본편 후보 / 2~4초 HOOK 후보 랭킹
python3 make_short.py rank --job $JOB --top 5

# 3) 사람이 대본을 읽고 고른 구간으로 렌더
python3 make_short.py render --job $JOB \
  --hook 00:31:04.2 00:31:07.4 \
  --body 00:30:58.0 00:31:52.5 \
  --headline "타도의 대상이 된 지지자들"
```

결과물은 `build/short.mp4`.

## 단계별 동작

| 단계 | 하는 일 |
|------|---------|
| `fetch` | `yt-dlp --download-sections` 로 지정 구간만 부분 요청, `--force-keyframes-at-cuts` 로 경계 정확도 확보. YouTube 자동자막(수 KB 사이드카)을 받아 지정 구간으로 잘라 `transcript.json` 생성. 자막이 없으면 받아둔 구간 오디오에만 faster-whisper 를 돌린다. |
| `rank` | cue 경계에 맞춘 45~60초 창을 전부 훑어 주제 키워드로 점수화. 서로 다른 주제 축이 함께 잡힐수록 가산점을 줘서 한 단어만 반복되는 구간을 걸러낸다. 겹치는 후보는 최고점 하나만 남긴다. HOOK 후보는 2~4초 안에 떨어지는 실제 발화 한 덩어리만 대상으로 하고, 문장이 끝나는 발화에 가산점을 준다. |
| `render` | 얼굴 중심 세로 크롭 → 1080×1920 → HOOK(헤드라인 오버레이) + 0.25초 페이드 전환 + 본편 → loudnorm(-14 LUFS) → H.264/AAC/faststart. |

## 설계상 지켜지는 제약

- **없는 말을 만들지 않는다.** HOOK 문장과 후보 대본은 전부 원본 자막/STT 에서 그대로 온다.
  스크립트는 문장을 생성하거나 재작성하지 않는다.
- **최종 선정은 사람이 한다.** `rank` 의 점수는 후보를 좁히는 용도이고, 맥락이 잘려 의미가
  왜곡되는지는 대본을 직접 읽고 판단해야 한다.
- **자의적 연결 없음.** `render` 는 HOOK 1구간 + 본편 1구간만 받는다. 떨어진 발언을 이어붙이는
  다중 컷 모드는 의도적으로 넣지 않았다.
- **얼굴이 잘리지 않는다.** 세로 크롭은 높이를 그대로 두고 9:16 폭만 잘라내며, 크롭 x 는
  프레임 밖으로 나가지 않게 클램프된다. `--face-x auto` 는 구간을 1fps 로 샘플링해
  얼굴 중심 x 의 중앙값을 쓰고, 못 찾으면 중앙 크롭으로 떨어진다.
- **예능식 효과 없음.** 줌, 밈, 효과음, 자동 점프컷이 없다. 전환은 0.25초 페이드 하나뿐이다.

## 옵션

| 옵션 | 기본값 | 설명 |
|------|--------|------|
| `--face-x` | `auto` | `auto` 또는 0~1 (프레임 폭 대비 얼굴 중심). 자동 결과가 불안하면 숫자로 고정. |
| `--transition` | `0.25` | HOOK→본편 전환 길이(초). |
| `--fps` / `--crf` | `30` / `18` | |
| `--font` | 자동탐색 | 한글 `.ttf`/`.otf` 경로. |
| `--out` | `build/short.mp4` | |

`render` 는 HOOK 이 2~4초를 벗어나거나 완성본이 50~65초를 벗어나면 경고를 출력한다(중단하지는 않는다).

## 검증 상태

`rank` 와 `render` 는 합성 소스로 동작을 확인했다 — VTT 파싱/롤업 중복 제거, 키워드 창 랭킹,
9:16 크롭, 헤드라인 오버레이(HOOK 에만 표시), 0.25초 전환, 1080×1920 H.264/AAC 출력.
`fetch` 는 YouTube 접근이 가능한 환경에서 확인이 필요하다.

## 알려진 환경 제약

- **ffmpeg `drawtext`**: `imageio-ffmpeg` 가 제공하는 바이너리에는 libfreetype 이 없어
  `drawtext` 가 빠져 있다. 그래서 헤드라인은 Pillow 로 PNG 를 그려 `overlay` 로 합성한다.
  어느 ffmpeg 빌드에서나 동작하고, 박스/여백/줄바꿈 제어도 더 정확하다.
- **Claude Code 웹 세션**: 조직 egress 정책이 `www.youtube.com:443` 을 차단하므로
  이 컨테이너 안에서는 `fetch` 가 동작하지 않는다. YouTube 가 열린 환경에서 실행해야 한다.
